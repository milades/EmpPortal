# ADR 0005: ذخیره‌سازی Hybrid و نسخه‌بندی فرم‌ها

## وضعیت

پذیرفته‌شده برای فاز ۲.

## تصمیم

- هر فرم یک موجودیت منطقی با Slug، زمان‌بندی، سیاست ارسال و چرخه عمر مستقل است.
- ساختار قابل اجرا در `FormVersion` به‌صورت JSON نسخه‌دار ذخیره می‌شود.
- نسخه منتشرشده immutable است؛ هر تغییر پس از انتشار، نسخه Draft جدید می‌سازد.
- هر Submission همیشه به نسخه دقیق فرم متصل می‌شود تا مشاهده و چاپ تاریخی پایدار بماند.
- پاسخ کامل Submission در JSON ذخیره می‌شود و مقادیر قابل گزارش هم‌زمان در جدول Typed Answer Index
  نگهداری می‌شوند.
- برای هر فرم جدول SQL جداگانه ساخته نمی‌شود.
- فایل و امضا، Workflow و نمودار در فاز ۲ پیاده نمی‌شوند، اما شناسه نسخه فرم و قراردادهای سرویس
  برای اضافه‌شدن آن‌ها در فازهای بعد حفظ می‌شوند.

## دلایل

ذخیره صرفاً JSON برای گزارش و ایندکس‌گذاری حجیم مناسب نیست و تولید جدول مستقل برای هر فرم باعث
Migration پویا، پیچیدگی Backup و ریسک عملیاتی می‌شود. مدل Hybrid انعطاف Schema را با گزارش‌گیری
تایپ‌شده و قابل ایندکس ترکیب می‌کند.

## امنیت

- فرم‌ساز اجازه اجرای JavaScript یا HTML خام دلخواه نمی‌دهد.
- Rich Text در زمان ذخیره و نمایش با Allowlist پاک‌سازی خواهد شد.
- شرط‌ها و فرمول‌ها با DSL محدود اجرا می‌شوند و امکان اجرای C#، SQL یا JavaScript ندارند.
